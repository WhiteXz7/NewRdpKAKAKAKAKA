# Armadura de Ferro Completa (R6 Roblox) + Variações Históricas

Este repositório contém uma **armadura de ferro completa** (europeia, séc. XV) e
suas **variações históricas pelo mundo** (samurai japonês, chahar-aina
persa/otomano, brigandine chinês Ming, lamellar mongol e coreano), modeladas e
animadas **do zero em Python** — sem Blender e sem Cascadeur — e prontas para o
**rig R6 do Roblox**.

Tudo está em [`armor_r6/`](armor_r6/):

- **Modelos 3D**: OBJ/MTL, glTF 2.0 (.glb) com esqueleto R6 + skinning
- **Animações**: Idle / Walk / Run (BVH + KeyframeSequence Lua)
- **Scripts Roblox**: instalação (solda) e animações
- **Previews** PNG renderizados por um rasterizador próprio

Comece por [`armor_r6/README.md`](armor_r6/README.md) e pela
[pesquisa histórica](armor_r6/PESQUISA_ARMADURAS.md).
